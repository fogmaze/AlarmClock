# Lazy alarm clock
Lazy Alarm Clock is a fork of Simple Alarm Clock. Since now it's not that simple so I changed the name.

# New features
 - AI based waking process utilizing the rear camera enables remote gesture control and checks whether you are awake or not by detecting faces and body parts.
 - Must-wake mode that will maximize the alarm volume after a given time.

With this feature, you can close the alarm without leaving the bed. 
# Open source
The application code is branched from AOSP and is open source. Additional feature requests are appreciated! You can submit bugreports and feature requests by sending an email to developers!
